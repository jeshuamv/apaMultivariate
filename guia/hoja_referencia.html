De tus datos a las tablas APA en Word
Ejecuta cada línea con Ctrl + Enter (Mac: Cmd + Enter)

0Instalar (una sola vez)

install.packages("remotes")
remotes::install_github("jeshuamv/apaMultivariate")

Crea un script con todo el análisis explicado. Cambia solo lo marcado con >>> CAMBIA AQUÍ <<<.

2Leer y revisar los datos

library(lavaan)
datos <- leer_datos()          # abre una ventana
datos <- leer_datos("encuesta.sav", perdidos = c(99))
names(datos)                   # nombres de columnas
revisar_datos(datos, modelo)   # antes de estimar

Lee Excel, SPSS, CSV (coma o punto y coma), Stata, SAS y texto.

3Escribir el modelo

modelo <- "
  F1 =~ i1 + i2 + i3     # =~  el factor se mide con
  F2 =~ i4 + i5 + i6
  F2 ~  F1               # ~   F1 influye en F2
  i1 ~~ i2               # ~~  covarianza / correlación
"

Los nombres deben ser idénticos a las columnas (mayúsculas incluidas).

4Estimar y revisar

fit <- cfa(modelo, data = datos)   # sem() si hay ~
revisar_modelo(fit)    # avisos de lavaan en español
# sin normalidad multivariada:
fit <- cfa(modelo, data = datos, estimator = "MLR")
# ítems con menos de 5 opciones:
fit <- cfa(modelo, data = datos, ordered = TRUE)
# si decides quitar los atípicos (repórtalo):
datos <- quitar_atipicos(datos, modelo)

5Tablas

Datos y supuestos

tabla_atipicos(fit)Mahalanobis, p1 y p2
Análisis factorial
tabla_factorabilidad(items)KMO, Bartlett, paralelo, MAP
tabla_cargas(afe o fit)Cargas, h², R²
tabla_confiabilidad(fit)α (IC), ω, r ítem-total
tabla_validez(fit)CR, AVE, Fornell-Larcker
tabla_htmt(fit)Validez discriminante HTMT
tabla_bifactor(fit)ωH, ECV, PUC, H, FD

Ajuste

Trayectorias y SEM

9Criterios de referencia

CFI, TLI≥ .95 (≥ .90 aceptable)
RMSEA≤ .06 (≤ .08 aceptable)
SRMR≤ .08
Carga estandarizada≥ .50 (ideal ≥ .70)
α, ω, CR≥ .70
AVE> .50; √AVE > correlaciones
HTMT< .85
KMO≥ .60 (mejor ≥ .80)
Indirecto (bootstrap)IC que no incluye el 0

Son convenciones, no leyes: cita su fuente. Cómo interpretarlos y redactarlos: guía INTERPRETACION.md.

Errores comunes: mayúsculas distintas · comillas sin cerrar · paréntesis sin cerrar · no correr las líneas en ordenv0.9.0

apaMultivariate · lista para reportar un AFC o un SEM

Basada en los estándares de reporte de APA (JARS-Quant, tabla 7; Appelbaum et al., 2018)
Tú = lo tienes que escribir o justificar tú

Resumen (abstract)
